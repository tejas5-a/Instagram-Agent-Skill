# Command: `/ig-comment`

## Overview
Generates high-value, thoughtful, relationship-building comments to leave on peer and industry accounts. 

> 🚫 **Operating Mandate**: Avoid spam, generic one-word remarks (*"Great post! 🔥"*), copy-paste templates, or self-promotional pitches.

## Trigger & Syntax
```bash
/ig-comment [postTopic="..."] [postContent="..."] [angle="additive-insight|shared-experience|respectful-challenge"]
```

## Strategy: The Value Comment Technique
Meaningful comments on accounts with your target audience generate authentic curiosity profile visits. A great comment:
1. Validates a specific point made by the creator.
2. Adds a short real-world data point or personal lesson.
3. Sparks a dialogue without hijacking the thread.

## Output Format
1. **Insightful Add-On**: Builds on the creator's framework.
2. **Personal Anecdote**: Relatable micro-story confirming the premise.
3. **Conversational Follow-Up**: Thoughtful question prompting a reply.
