# Command: `/ig-repurpose`

## Overview
Transforms existing long-form content, YouTube transcripts, blog articles, podcast show notes, or tweet threads into native, high-retention Instagram assets.

## Trigger & Syntax
```bash
/ig-repurpose [content="..."] [sourceFormat="blog|podcast|tweet|newsletter"]
```

## Cross-Format Adaptation Rules
- **Text to Reel**: Extract the single most surprising paradox or contrarian insight and turn it into a 30s conversational script.
- **Text to Carousel**: Break down linear steps or lists into a 7-slide visual deck.
- **Text to Story Arc**: Create a 3-slide interactive poll and behind-the-scenes summary.
- **Text to Single Post**: Distill into an aesthetic quote or infographic outline.

## Output Format
1. **Reel Adaptation (Hook + Script)**
2. **Carousel Adaptation (Slide by Slide Outline)**
3. **Interactive Story Arc (Sticker Idea)**
4. **Feed Caption & Hashtags**
