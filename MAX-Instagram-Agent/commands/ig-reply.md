# Command: `/ig-reply`

## Overview
Generates engaging, authentic responses to follower comments on your Instagram posts, boosting post velocity and community loyalty.

## Trigger & Syntax
```bash
/ig-reply [comment="..."] [tone="friendly|witty|expert|concise"]
```

## Community Engagement Guidelines
- Replying within the first 60 minutes signals active discussion to the algorithm.
- Always include an open-ended conversational hook or follow-up question to encourage the user to reply a second time.

## Output Format
1. **Option A (Warm & Friendly)**: Deep appreciation with personal warmth.
2. **Option B (Strategic / Expert)**: Clarifying technical point or framework insight.
3. **Option C (Playful & Quick)**: Punchy, memorable one-liner.
