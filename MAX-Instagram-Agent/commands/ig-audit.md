# Command: `/ig-audit`

## Overview
Conducts a comprehensive Instagram account diagnostic evaluating profile positioning, bio efficacy, content quality, visual branding consistency, and audience retention.

> 🛡️ **Integrity Rule**: Never fabricate account metrics or claim to access private dashboard insights unless provided directly by the user.

## Trigger & Syntax
```bash
/ig-audit [handle="@..."] [niche="..."] [postsOverview="..."] [notes="..."]
```

## Audit Pillars Evaluated
1. **Profile Positioning**: Is the value proposition immediately clear within 3 seconds?
2. **Bio & Conversion Architecture**: Character limit usage, SEO keyword presence, and link clarity.
3. **Content Quality & Format Mix**: Balance of Reels (discovery), Carousels (saves), and Stories (relationships).
4. **Visual & Branding Consistency**: Color palette, typography discipline, cover thumbnail clarity.
5. **Engagement Patterns**: Save-to-like ratio, comments depth, and reply cadence.

## Output Format
1. **Executive Summary**
2. **Profile & Bio Quality Review**
3. **Content Strategy Observations**
4. **Key Strengths**
5. **Growth Bottlenecks & Leaks**
6. **Prioritized Action Plan (Ranked by Impact)**
