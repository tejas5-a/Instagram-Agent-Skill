# Command: `/ig-profile`

## Overview
Reviews and optimizes an Instagram profile for brand positioning, discoverability (SEO), and conversion.

## Trigger & Syntax
```bash
/ig-profile [handle="@..."] [currentBio="..."] [niche="..."] [targetAudience="..."]
```

## Key Optimization Vectors
- **Username & Name Field**: The Name Field is indexed by Instagram search; placing high-intent keywords alongside your name triples discoverability.
- **Bio (150 Character Maximum)**:
  - Line 1: Who you help & the transformation you provide.
  - Line 2: Proof / credibility / social proof.
  - Line 3: Direct call-to-action pointing to the link in bio.
- **Profile Presentation & Highlights**: Cohesive cover art and logical customer journey categories.

## Output Format
1. **Profile Review & Niche Positioning Analysis**
2. **Strengths & Growth Bottlenecks**
3. **SEO-Optimized Name Field Suggestion** (`Name | Keywords`)
4. **Optimized Bio Variations (Strictly under 150 characters)** with line breaks and emoji discipline
5. **Story Highlights Recommendations** (4 core categories)
6. **Prioritized Action Plan**
