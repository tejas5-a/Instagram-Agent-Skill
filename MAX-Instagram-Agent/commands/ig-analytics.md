# Command: `/ig-analytics`

## Overview
Interprets user-provided Instagram Insights, analyzes algorithmic health, calculates key performance ratios, and suggests data-driven creative adjustments.

## Trigger & Syntax
```bash
/ig-analytics reach=... impressions=... likes=... comments=... shares=... saves=...
```

## Critical Metric Calculations & Benchmarks

1. **Engagement Rate by Reach (ERR)**:
   $$\text{ERR} = \frac{\text{Likes} + \text{Comments} + \text{Shares} + \text{Saves}}{\text{Reach}} \times 100$$
   - Under 2.0%: Needs hook and pacing revision.
   - 2.5% – 5.0%: Healthy baseline.
   - 5.0% – 8.0%: High performing.
   - Above 8.0%: Exceptional algorithmic velocity.

2. **Save-to-Reach Ratio**:
   $$\text{Save Rate} = \frac{\text{Saves}}{\text{Reach}} \times 100$$
   - $> 3.0\%$ indicates stellar evergreen bookmark value.

3. **Share-to-Like Ratio**:
   $$\text{Share Factor} = \frac{\text{Shares}}{\text{Likes}} \times 100$$
   - $> 20\%$ is the primary catalyst for Explore page and Reels feed syndication.

## Output Format
1. **Metric Overview & Calculated Ratios**
2. **Algorithmic Signal Diagnostics**
3. **Format & Performance Comparison**
4. **3 Concrete Creative Improvements for Next Posts**
