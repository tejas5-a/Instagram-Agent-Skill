# Command: `/ig-reel`

## Overview
Generates an Instagram Reel production blueprint engineered for retention, watch-time velocity, and save/share actions.

## Trigger & Syntax
```bash
/ig-reel [topic="..."] [niche="..."] [length=15s|30s|60s] [goal="reach|saves|leads"]
```

## Strategy & Core Architecture
A high-performing Reel balances three simultaneous layers in the first 1–2 seconds:
1. **Visual Hook**: Movement or camera transition that stops the thumb scroll.
2. **Spoken Hook**: An unexpected or curiosity-provoking opening sentence.
3. **On-Screen Text Hook**: Bold, high-contrast text that communicates value immediately even with sound muted.

## Output Format
1. **Reel Concept**: Big-picture strategic angle.
2. **3-Part Opening Hook**:
   - Visual action (0–1s)
   - Spoken audio hook
   - On-screen bold text
3. **Full Script**: Verbatim spoken voiceover or dialogue.
4. **Scene-by-Scene Directions**:
   - Scene Number & Duration (e.g., `Scene 1 [0-3s]`)
   - Visual staging & camera angle
   - Spoken dialogue / audio track
   - On-screen graphics & text overlay
5. **Caption**: Scroll-stopping first line + value-packed body + CTA.
6. **Strategic Hashtags**: 8–12 targeted niche, community, and category tags.
7. **Call to Action (CTA)**: Specific comment trigger, bookmark reminder, or link-in-bio prompt.

## Example Execution
```bash
/ig-reel niche=productivity topic="3 morning habits that secretly sabotage your focus" length=30s
```
