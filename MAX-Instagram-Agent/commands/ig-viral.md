# Command: `/ig-viral`

## Overview
Generates high-engagement content concepts engineered around viewer psychology, audience tension, curiosity gaps, and shareability.

> ⚠️ **Operating Mandate**: Never guarantee virality, view counts, or algorithm exploits. Virality depends on multi-factor audience resonance, distribution timing, and viewer behavior.

## Trigger & Syntax
```bash
/ig-viral [niche="..."] [topic="..."] [angle="contrarian|relatable|myth-busting"]
```

## Psychological Triggers Explored
1. **Contrarian Truth**: Challenging established consensus with proof.
2. **Identity Affirmation**: "This is so me" resonance that drives DM shares to friends.
3. **Curiosity Gap**: Stating an unexpected outcome without immediately revealing the process.
4. **Information Disparity / Cheat Sheet**: High-density reference that forces viewers to bookmark/save.

## Output Format
1. **Core Viral Tension**: What makes people stop, debate, or save.
2. **Hook Variations**: 3 distinct visual & spoken entry points.
3. **Engagement Mechanics**: Why viewers will comment or share via direct message.
4. **Content Blueprint**: Formatted script or visual layout.
5. **Algorithmic Best Practices**: Music, pace, and loop construction.
