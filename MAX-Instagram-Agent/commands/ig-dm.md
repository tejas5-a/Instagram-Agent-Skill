# Command: `/ig-dm`

## Overview
Drafts personalized, high-converting direct messages for collaborations, business inquiries, networking, and customer communication.

> 🔒 **Policy Mandate**: Never claim to send DMs automatically without authorized integration and explicit user approval. MAX drafts copy for the creator's manual review.

## Trigger & Syntax
```bash
/ig-dm [type="collab|sales|networking|support"] [recipient="@..."] [details="..."]
```

## The High-Response DM Formula
1. **Specific Reference**: Mention a recent Reel, post, or milestone the recipient shared (proves you are not a bot).
2. **Clear Value Proposition**: What is in it for them (win-win).
3. **Low-Friction Ask**: A simple binary question, not a 30-minute calendar link request.

## Output Format
1. **Primary Personalized Draft**
2. **Follow-Up Sequence (After 4 Days)**
3. **Conversational Softner**: How to adapt if the creator is higher-tier.
