# Command: `/ig-carousel`

## Overview
Designs complete multi-slide swipeable Instagram carousels engineered for high save rates, dwell time, and shares.

## Trigger & Syntax
```bash
/ig-carousel [topic="..."] [slides=5-10] [niche="..."] [goal="education|framework|story"]
```

## Carousel Pacing Architecture
- **Slide 1 (Cover)**: High-contrast title + subtitle + visual curiosity. Must justify the swipe.
- **Slide 2 (The Hook / Problem Validation)**: Agitate the pain point or set up the context.
- **Slides 3–6 (Actionable Insights / Steps)**: One core concept per slide. Clear headline + bite-sized explanation.
- **Slide 7/8 (Summary / Key Takeaway)**: Digestible recap.
- **Final Slide (CTA Slide)**: Clear next step (Save for later, follow, comment a keyword).

## Output Format
1. **Cover Slide**: Headline, Subtitle, and visual layout suggestion.
2. **Slide-by-Slide Content**: Numbered slides with exact slide text and visual art direction.
3. **Final CTA Slide**: Graphic layout with specific conversion prompt.
4. **Accompanying Caption**: Brief post caption and hashtags to pair with the carousel.
